# Video Games Quiz

A mobile application designed to test players' knowledge of popular video games through an interactive, multi-question quiz interface. 

# Features Highlight

* **ScrollView:** Used as the main container to let users scroll smoothly through the entire page of questions.
* **Custom Component (VideoGames):** A reusable component built to display the question text, FontAwesome icons, and game posters.
* **Picker (@react-native-picker/picker):** Dropdown menus used for each question so players can select their answers.
* **State Hooks (useState):** Used to capture and track the user's selected answers across all questions.
* **handleSubmit Function:** Processes player selections, checks them against correct answers using strict equality, and calculates the total score.
* **Alert.alert (Feedback & Results):** Pops up a modal dialog box to show the final score alongside a conditional feedback message.
* **TouchableOpacity (Show Answers):** Wraps text to create a clickable button that displays the correct answers in an alert popup when tapped.
